# User documentation

This directory holds only files that help a user adopt, configure and use `agent-okta-d`: install, getting started, configuration reference, usage examples and troubleshooting.

It is not for design, requirements, spec or process material, and it must not link into `specs/`. Design and requirements live in `docs/` and the PRD at the repository root.

The tool is not implemented yet, so there are no user guides to publish. They will be added here as features ship.
